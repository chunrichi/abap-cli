## `abap pull`

Download ABAP objects from SAP to local files.

```bash
abap pull [options] [object-name]
```

| Option | Description |
| --- | --- |
| `--type <type>` | Object type (CLAS, PROG, INTF, etc.). |
| `--package <package>` | Download all objects in a package (bounded by --limit). |
| `--limit <n>` | Batch page size for --package. |
| `--page <n>` | Batch page number for --package (1-based). |
| `--dir <path>` | Output directory. |
| `--overwrite` | Replace local file with different content. |
| `--skip-existing` | Skip files that already exist. |
| `--include-tests` | Include testclasses source part. |
| `--include-all-parts` | Include every source-code part. |
| `--textpool` | Also pull textpool files (.texts/.selections/.headings.<lang>.properties). |
| `--active` | Pull the active (activated) version — the source `abap run` executes. Default: the working-area/latest version. |
| `--remote <remoteid>` | Pull the object's active version source from a remote system (Version Management). |
| `--tr <request>` | Pull all objects bound to a transport request (mutually exclusive with object name and --package). |
| `--user <sap-user>` | Filter --tr lookups by transport task owner (case-insensitive). Only valid with --tr. |

- Pull a single class

  ```bash
  abap pull ZCL_MY_CLASS --type CLAS
  ```
- Pull a whole package

  ```bash
  abap pull --package ZPKG --limit 50
  ```

## `abap push`

Push local ABAP files to SAP: lock → set source → syntax check → activate → unlock.

```bash
abap push [options] [files...]
```

| Option | Description |
| --- | --- |
| `--all` | Push all .abap files under the scan root (sourceDir or current dir; honours .abapignore). |
| `--tr <transport>` | Transport number override for unbound objects. |
| `--check-only` | Syntax check only; do not activate. Not supported for ICF-routed or channel-routed JSON files (DDIC / HTTP / TRAN / TTYP / MSAG / DDLS) — those are validated during push. |
| `--no-activate` | Lock + write + skip check + skip activate + unlock. |
| `--dry-run` | Plan only — no mutating ADT calls. |
| `--fail-fast` | Stop at the first failing file (default: --keep-going). |
| `--atomic` | Validate all files first; write nothing if any file fails validation. |
| `--yes` | Confirm in non-interactive mode. |

- Push a single file

  ```bash
  abap push src/zcl_demo.clas.abap --tr DEVK900001
  ```
- Push all files under cwd

  ```bash
  abap push --all --tr DEVK900001 --yes
  ```

## `abap check`

Validate ABAP source code (syntax / content / atc).

```bash
abap check [syntax|content|atc] [options]
```

| Option | Description |
| --- | --- |
| `--variant <variant>` | ATC check variant (required with `check atc`). |
| `--all` | Check all .abap files under the scan root (sourceDir or current dir). |
| `--changed` | Check only files changed since the SAP version. |
| `--strict` | Treat warnings as failures. |
| `--out [file]` | Persist raw ATC worklist to a file (only with `check atc`); defaults to .abap/atc/<variant>-<timestamp>.json. |
| `--files <files...>` | Shortcut: run syntax mode on the given files (equivalent to `abap check syntax <files...>`). |

- Syntax check

  ```bash
  abap check syntax src/zcl_demo.clas.abap
  ```
- Local-only validation

  ```bash
  abap check content src/zcl_demo.clas.abap
  ```

## `abap create`

Create a new ABAP source object (CLAS, INTF, PROG, FUGR) and activate it

```bash
abap create <type> <name> [options]
```

| Option | Description |
| --- | --- |
| `--package <package>` | Target SAP package (required) |
| `--description <desc>` | Object description (required) |
| `--tr <transport>` | Transport number |
| `--no-activate` | Create the object but do not activate it |
| `--template <template>` | Skeleton template |
| `--no-pull` | Skip the create-then-pull local copy (default: pull after create) |
| `--check-only` | Validate the proposed object without creating it |
| `--audit` | Include the before-checksum (extra SAP round-trip, off by default) |
| `--overwrite` | When pulling the new object back, replace an existing local file (default: keep the local draft) |
| `--file <path>` | abap-file-format JSON input (required for TABL/STRU/DOMA/DTEL/ENQU/NROB/HTTP/TRAN/TTYP/MSAG/DDLS/SRVD/DCLS/DDLX/DDLA) |
| `--func <name>` | With FUGR: create a function module (FUGR/FF) inside the existing function group <name> |
| `--software-component <swcomp>` | With DEVC: software component of the new package (default: inherited from the super package) |
| `--transport-layer <layer>` | With DEVC: transport layer of the new package (default: inherited from the super package) |
| `--package-type <type>` | With DEVC: package type |
| `--yes` | Confirm in non-interactive environments. |
| `--non-interactive` | Alias of --yes. |

## `abap delete`

Delete an ABAP object from SAP (lock → delete → unlock). Type is required to avoid ambiguity; --yes is required for non-interactive confirmation; a transport request is required for non-$TMP objects (matching `abap push` semantics).

```bash
abap delete <object> --type <type> [--tr <request>] --yes
```

| Option | Description |
| --- | --- |
| `--type <type>` | Object type code (CLAS, PROG, INTF, FUGR, TABL, ...). |
| `--tr <request>` | Transport request number (required for non-$TMP packages). |
| `--yes` | Confirm the deletion. Required — there is no implicit confirmation. |

- Delete a local $TMP class

  ```bash
  abap delete ZCL_ZR_CHK9 --type CLAS --yes
  ```
- Delete a transport-bound object

  ```bash
  abap delete ZR_OLD --type PROG --tr NDK900123 --yes
  ```

## `abap list`

List ABAP objects in a package (read-only, ADT quickSearch-backed). Useful for cleaning up scratch objects or auditing a package before mass pull/push.

```bash
abap list --package <pkg> [--type <type>] [--limit <n>]
```

| Option | Description |
| --- | --- |
| `--package <package>` | Filter by package (e.g., $TMP). Required. |
| `--type <type>` | Filter by object type (CLAS, PROG, INTF, ...). |
| `--limit <n>` | Max results (default 20). |

- List everything in $TMP

  ```bash
  abap list --package '$TMP'
  ```
- List every local scratch class

  ```bash
  abap list --package '$TMP' --type CLAS
  ```
