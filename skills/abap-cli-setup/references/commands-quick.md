## `abap init`

Initialize the workspace — bind a profile, write .abap.json, inspect, clear fields, or scaffold AI agent context.

```bash
abap init [options]
```

| Option | Description |
| --- | --- |
| `--profile <name>` | Use an existing global profile (created with `abap profile add`). |
| `--url <url>` | SAP system URL (TTY wizard only). |
| `--client <client>` | SAP client number. |
| `--username <user>` | SAP username. |
| `--password <password>` | SAP password (stored in keychain). |
| `--language <language>` | SAP language. |
| `--insecure` | Skip SSL certificate verification (development only). |
| `--ca <path>` | PEM CA certificate to import into ~/.abap-cli/certificates/ and bind to this profile. |
| `--tr <transport>` | Default transport number (written to .abap.json). |
| `--package <package>` | Default SAP package (written to .abap.json). |
| `--source-dir <path>` | Base directory for `push --all` / `check --all` (written to .abap.json). |
| `--show-config` | Print the current workspace config (.abap.json) as JSON and exit. |
| `--unset-package` | Remove the `package` key from .abap.json. |
| `--unset-tr` | Remove the `transport` key from .abap.json. |
| `--unset-source-dir` | Remove the `sourceDir` key from .abap.json. |
| `--test-connection` | Probe TLS + auth and report results (implies --test-tls --test-auth). |
| `--test-tls` | Probe the TLS handshake. |
| `--test-auth` | Probe authentication (after TLS). |
| `--agent <target>` | Scaffold agent context files. One of: agents \| copilot \| claude \| cursor \| generic. |
| `--force` | Overwrite existing files when scaffolding --agent (default: skip). |
| `--yes` | Skip all prompts; fail if required input is missing. |
| `--non-interactive` | Alias of --yes. |

- First-time bind

  ```bash
  abap init --profile DEV --tr DEVK900001 --package Z_MY_PACKAGE --yes
  ```
- Inspect current config

  ```bash
  abap init --show-config
  ```

## `abap profile`

Manage global connection profiles (list / show / add / set / test / delete / export / import).

```bash
abap profile <command> [options]
```

| Option | Description |
| --- | --- |
| `--url <url>` | SAP system URL. |
| `--client <client>` | SAP client number. |
| `--username <user>` | SAP username. |
| `--language <lang>` | SAP language. |
| `--password <password>` | Password (stores credential in keychain). |
| `--remove-password` | Drop the stored password from keychain. |
| `--insecure` | Skip SSL certificate verification (development only). |
| `--ca <path>` | PEM CA certificate to import into ~/.abap-cli/certificates/ and bind to this profile. |
| `--clear-ca` | Remove the CA certificate setting. |
| `--file <path>` | Bundle file path for export / import. |
| `--with-passwords` | Include passwords in the export bundle (warned opt-in). |
| `--overwrite` | Update profiles that already exist on import. |
| `--yes` | Confirm in non-interactive mode. |

- Add a profile

  ```bash
  abap profile add DEV --url https://... --username DEV --password ***
  ```
- Test a profile

  ```bash
  abap profile test DEV
  ```

## `abap deploy`

Deploy bundled ICF ABAP service to SAP.

```bash
abap deploy [options] | abap deploy status [options]
```

| Option | Description |
| --- | --- |
| `--tr <transport>` | Transport number (required when --package is not $TMP). |
| `--package <package>` | Target SAP package (default $TMP — local, no transport needed). |
| `--dry-run` | Plan only — make no mutating SAP calls. |
| `--diff` | Report per-file source differences. |
| `--dev` | Deploy the global-class development form (maintainers; skips the release merge). |
| `--force` | Bypass safety guards (forced: true in the result). |
| `--yes` | Confirm in non-interactive mode. |

- Deploy to $TMP (no transport)

  ```bash
  abap deploy --yes
  ```
- Deploy the global-class development form (maintainers)

  ```bash
  abap deploy --dev --yes
  ```

## `abap types`

Print the canonical CLI type ↔ TADIR PGMID/OBJECT ↔ DDIC tabclass mapping. Pure local — no SAP call. Surfaces the non-obvious mappings that cost real time when joining CLI write paths to TADIR queries (CLI HTTP ↔ TADIR SICF, CLI STRU ↔ TADIR TABL + DD02L-TABCLASS=INTTAB, etc.).

```bash
abap types [--json] | abap types <type> [--json]
```

| Option | Description |
| --- | --- |
| `--tadir-object` | With a single type, print only the TADIR OBJECT value (one line, no table). |
| `--json` | Emit a single JSON envelope (global flag). |

- Print the full type catalog

  ```bash
  abap types
  ```
- Look up a single type

  ```bash
  abap types HTTP
  ```
