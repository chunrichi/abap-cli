## `abap search`

Search for ABAP objects in SAP system

```bash
abap search [options] <query>
```

| Option | Description |
| --- | --- |
| `--type <type>` | Filter by SAP ADT object type. Common values: CLAS, INTF, PROG, FUGR, TABL, TABL/DT (transparent table), TABL/DB (pooled), TABL/DY (append structure), DOMA, DTEL, STRU, MSAG, TYPE, TTYP. |
| `--limit <n>` | Maximum results per page |
| `--page <n>` | Page number (1-based) |
| `--exact` | Exact name match (mutually exclusive with --fuzzy) |
| `--fuzzy` | Substring match (default) |
| `--package <package>` | Filter by package |
| `--page-all` | Fetch all results in one request (cap = --page-all-max × --limit; mutually exclusive with --page) |
| `--page-all-max <n>` | Page-count cap that sizes the --page-all single request |

- Filter by type

  ```bash
  abap search ZCL_* --type CLAS --limit 50
  ```
- Exact name match

  ```bash
  abap search ZCL_DEMO --exact
  ```

## `abap inspect`

View ABAP object metadata read-only (no local files required).

```bash
abap inspect [options] <object>
```

| Option | Description |
| --- | --- |
| `--structure` | Include structure elements. |
| `--includes` | Include class include parts. |
| `--locks` | Include lock / transport ownership (read-only). |
| `--package` | Include the object package name. |
| `--activation` | Verify active vs latest source per part (read-only; detect stale activation). |

- Inspect a class

  ```bash
  abap inspect ZCL_MY_CLASS
  ```
- Detect stale activation

  ```bash
  abap inspect ZCL_MY_CLASS --activation
  ```

## `abap pull`

Download ABAP objects from SAP to local files.

```bash
abap pull [options] [object-name]
```

| Option | Description |
| --- | --- |
| `--type <type>` | Object type (CLAS, PROG, INTF, etc.). |
| `--package <package>` | Download all objects in a package (bounded by --limit). |
| `--limit <n>` | Batch page size for --package. |
| `--page <n>` | Batch page number for --package (1-based). |
| `--dir <path>` | Output directory. |
| `--overwrite` | Replace local file with different content. |
| `--skip-existing` | Skip files that already exist. |
| `--include-tests` | Include testclasses source part. |
| `--include-all-parts` | Include every source-code part. |
| `--textpool` | Also pull textpool files (.texts/.selections/.headings.<lang>.properties). |
| `--remote <remoteid>` | Pull the object's active version source from a remote system (Version Management). |
| `--tr <request>` | Pull all objects bound to a transport request (mutually exclusive with object name and --package). |
| `--user <sap-user>` | Filter --tr lookups by transport task owner (case-insensitive). Only valid with --tr. |

- Pull a single class

  ```bash
  abap pull ZCL_MY_CLASS --type CLAS
  ```
- Pull a whole package

  ```bash
  abap pull --package ZPKG --limit 50
  ```

## `abap select`

Query table data read-only via the bundled ICF /data endpoint (SE16N equivalent): --table ZTAB [--fields ...] [--where ...] [--limit N] [--offset N] [--order-by ...] [--count-only]

```bash
abap select --table <name> [options]
```

| Option | Description |
| --- | --- |
| `--table <name>` | Target ABAP table or view name (e.g. ZTAB_FIXTURE). Uppercased and validated against DDIC on SAP side. |
| `--fields <csv>` | Comma-separated field names to project. Omit for all fields (large-object fields STRG/RSTR/LCHR/LRAW excluded, listed in data.excludedFields). |
| `--where <clause>` | Filter clause: FIELD OP VALUE joined by AND. Ops: = <> > >= < <= LIKE. Strings in single quotes ('' for escape), numbers bare, dates 'YYYYMMDD'. MANDT filter rejected (implicit session client). |
| `--limit <n>` | Maximum rows returned. SAP fetches limit+1 to detect truncation (data.truncated). |
| `--offset <n>` | Row offset for pagination. Deterministic pagination requires --order-by. |
| `--order-by <csv>` | Comma-separated FIELD:ASC\|DESC pairs, e.g. "ID:ASC,AMOUNT:DESC". |
| `--group-by <field>` | Aggregate: return one row per distinct value of <field> plus CNT (COUNT(*)), ordered by CNT descending. Mutually exclusive with --fields / --order-by / --offset / --count-only. |
| `--count-only` | Return only the matching row count (data.count); rows/fields omitted. |
| `--dry-run` | Plan only — print the query envelope without invoking the ICF endpoint. |
| `--json` | Emit the unified JSON envelope on stdout; --pretty-json indents. |

- Basic query with filter and limit

  ```bash
  abap select --table ZTAB_FIXTURE --where "STATUS = 'X'" --limit 50
  ```
- Projection + sort + pagination

  ```bash
  abap select --table ZTAB_FIXTURE --fields "ID,AMOUNT" --order-by "ID:ASC" --limit 20 --offset 40
  ```
