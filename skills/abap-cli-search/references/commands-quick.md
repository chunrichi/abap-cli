## `abap search`

Search for ABAP objects in SAP system

```bash
abap search [options] <query>
```

| Option | Description |
| --- | --- |
| `--type <type>` | Filter by SAP ADT object type. Common values: CLAS, INTF, PROG, FUGR, TABL, TABL/DT (transparent table), TABL/DB (pooled), TABL/DY (append structure), DOMA, DTEL, STRU, MSAG, TYPE, TTYP. |
| `--limit <n>` | Maximum results per page |
| `--page <n>` | Page number (1-based) |
| `--exact` | Exact name match (mutually exclusive with --fuzzy) |
| `--fuzzy` | Substring match (default) |
| `--package <package>` | Filter by package |
| `--page-all` | Fetch all results in one request (cap = --page-all-max × --limit; mutually exclusive with --page) |
| `--page-all-max <n>` | Page-count cap that sizes the --page-all single request |

- Filter by type

  ```bash
  abap search ZCL_* --type CLAS --limit 50
  ```
- Exact name match

  ```bash
  abap search ZCL_DEMO --exact
  ```

## `abap where-used`

Find direct SAP object references (read-only).

```bash
abap where-used <object> [options]
```

| Option | Description |
| --- | --- |
| `--type <type>` | Target object type. |
| `--ref-type <type>` | Filter references by object type. |
| `--package <package>` | Case-insensitive reference package filter. |
| `--limit <n>` | Maximum returned references. |

- Find references to a class

  ```bash
  abap where-used ZCL_TARGET --type CLAS
  ```
- JSON envelope via the references alias

  ```bash
  abap references ZTAB_TARGET --type TABL --ref-type TABL --json
  ```

## `abap inspect`

View ABAP object metadata read-only (no local files required).

```bash
abap inspect [options] <object>
```

| Option | Description |
| --- | --- |
| `--structure` | Include structure elements. |
| `--includes` | Include class include parts. |
| `--locks` | Include lock / transport ownership (read-only). |
| `--package` | Include the object package name. |
| `--activation` | Verify active vs latest source per part (read-only; detect stale activation). |
| `--versions` | Read the version history (ADT versions feed; read-only). |
| `--include <part>` | Include part for --versions: main \| definitions \| implementations \| macros \| testclasses (default main). |
| `--limit <n>` | Max version entries to return (default 50, max 200). |
| `--show <version>` | Return the source of one version (requires --versions). |
| `--out <path>` | Write the shown version source to a file instead of returning it. |
| `--symbols` | Flatten the class/interface structure into symbols with source line ranges. |
| `--kinds <list>` | Filter --symbols by kind, comma separated (method, attribute, …). |
| `--name-pattern <regex>` | Filter --symbols by name (case-insensitive regular expression). |

- Inspect a class

  ```bash
  abap inspect ZCL_MY_CLASS
  ```
- Detect stale activation

  ```bash
  abap inspect ZCL_MY_CLASS --activation
  ```

## `abap diff`

Compare local files against SAP (read-only) with a per-part change summary.

```bash
abap diff [options] [file]
```

| Option | Description |
| --- | --- |
| `--all` | Compare the whole workspace. |
| `--remote` | Only remote-only differences. |
| `--local-only` | Only local-only differences. |
| `--limit <n>` | Bounds the result. |

- Diff a single file

  ```bash
  abap diff src/zcl_demo.clas.abap
  ```
- Diff the workspace

  ```bash
  abap diff --all --limit 50
  ```

## `abap status`

Show local vs SAP sync status as a standardised changedParts list.

```bash
abap status [options]
```

| Option | Description |
| --- | --- |
| `--remote-only` | Only remote-only differences. |
| `--local-only` | Only local-only differences. |
| `--limit <n>` | Bounds the result; truncated: true when capped. |
| `--since <iso-date>` | Only files modified at or after the date (YYYY-MM-DD[THH:mm:ss]). |
| `--all` | Include unchanged entries. |

- Default sync status

  ```bash
  abap status
  ```
- Only remote-only

  ```bash
  abap status --remote-only --limit 50
  ```

## `abap dumps`

List recent ST22 ABAP runtime dumps through the read-only ADT feed.

```bash
abap dumps [options]
```

| Option | Description |
| --- | --- |
| `--limit <n> <n>` | Maximum number of recent dump summaries to return. The limit is sent to ADT as $top. |
| `--user <name> <name>` | Filter to an SAP user. Omit to use the current SAP login user; pass an empty value to query all users. |

- List the most recent runtime dump summaries

  ```bash
  abap dumps
  ```
- Agent integration: restrict the result to five compact entries

  ```bash
  abap dumps --limit 5 --json
  ```
